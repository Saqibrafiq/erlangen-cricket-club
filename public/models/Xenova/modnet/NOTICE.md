# MODNet portrait matting model

Used by the player editor to remove photo backgrounds in the editor's browser (ADR-0016).

- Model: MODNet, "Trimap-Free Portrait Matting in Real Time" by Zhanghan Ke et al., https://github.com/ZHKKKe/MODNet
- ONNX conversion: https://huggingface.co/Xenova/modnet (`onnx/model_quantized.onnx`)
- Licence: Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0

The files in this folder are unmodified copies of the conversion above.
